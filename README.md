I was frustrated having to navigate in windows when switching between programs. 
This collab with chatGPT watches explorer and logs my last path into memory.
I have it mapped to ctl+m and the when used, it uses a variant of sendkeys - sendraw to spit out the last folder I visited.
When switching between applications I no longer have to navigate thru the file structure to the folder I'm working on.
I simply hit ctl+m and I get the full path to my "hot folder" - the last folder I navigated to.

The AHK script is set to autorun at login.
